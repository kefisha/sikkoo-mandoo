# Siikkoo-Mandoo Students Association · MWU Digital Portal (v2.0)

## Features Included
- **Modern ALLS-Style Login & Portal UI**: Role selector cards (Student, Campus Rep, Committee, Admin), gradient 3D buttons, glassmorphism, Dark/Light mode, Mobile Bottom Navigation, and PWA (Add to Home Screen).
- **Ethiopian Calendar Integration**: Automatic Ethiopian date display alongside Gregorian dates across dashboard, ID cards, events, meetings, and certificates.
- **Digital Membership ID Card**: QR verification, official SVG Seal, and 1-click PNG download.
- **Member Profile Settings**: Students can update phone, year, photo (auto-compressed), and password.
- **Online Elections & Polls**: 1-member-1-vote system with live percentage bars.
- **Digital Certificate Generator**: Issue & download official PNG certificates with QR verification.
- **Student Q&A Forum**: Campus & academic discussion threads for freshmen and seniors.
- **Admin Dashboard**: Interactive Chart.js analytics, full member management + Excel (CSV) export, finance reports, meetings, leadership, audit logs, Telegram auto-post, and JSON backup.

## Deployment (Render)
1. Upload these files to your GitHub repository.
2. Connect the repository to Render (Web Service, Node 20).
3. Set `DATABASE_URL` in Render Environment Variables.
4. Build Command: `npm install` | Start Command: `npm start`.
